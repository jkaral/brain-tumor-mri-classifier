# Dataset location

The dataset is intentionally excluded from version control. Source: Masoud Nickparvar, [Brain Tumor MRI Dataset on Kaggle](https://www.kaggle.com/datasets/masoudnickparvar/brain-tumor-mri-dataset).

Expected extracted layout for training or evaluation work:

```text
brain-tumor-mri-dataset/
├── Training/
│   ├── glioma/
│   ├── meningioma/
│   ├── pituitary/
│   └── notumor/
└── Testing/
    ├── glioma/
    ├── meningioma/
    ├── pituitary/
    └── notumor/
```

Review the licence and usage terms on the Kaggle source page before downloading or reusing the images. Do not commit the 83 MB working archive or extracted image folders.
